# Sherouk Shaaban – QA Engineer Portfolio

Personal portfolio of **Sherouk Shaaban Mahmoud**, Quality Control Engineer (manual, API and automation testing). ISTQB® CTFL v4.0.

**Live site:** https://sherouk2022.github.io

## What's inside

- A career journey roadmap, from university to BDD automation
- Experience at Mdarj, Nahr Development and Faainex, with an interactive project timeline, a products-by-company donut chart and a platforms bar chart
- A system map of the SJC Tansiq case study (6 roles, 16 modules) and an animated toolkit graphic
- Case study: SJC Tansiq, with a 4,817-case test plan and 1,200+ automated Cucumber BDD scenarios
- 14 projects you can filter by company
- Testing process, skills, certifications and contact details
- Light and dark theme, responsive layout, downloadable CV

## Tech

Plain HTML, CSS and JavaScript in one `index.html` file. There's no build step and no framework. The charts and icons are inline SVG. The site is hosted on GitHub Pages.

```
.
├── index.html                  # the whole site
├── assets/
│   └── Sherouk_Shaaban_CV.pdf  # downloadable CV
└── README.md
```

## Run locally

Open `index.html` in any browser.
